# 《表面之下》CTF 黑客主题宣传片

版本：逐镜头制作脚本 v1.0。

片长 150 秒；1920×1080；30fps；共 4500 帧。所有时间段采用左闭右开，00:00–00:03 对应第 0–89 帧。

主体是 CTF 解题与黑客视角，俱乐部元素通过 Logo、蓝色视觉、队伍名称和片尾落版少量融入。五道挑战作为同一场比赛中的独立赛题，由队伍分工推进；Pwn 题保留到终局。赛事、对手、积分与一血通知均为剧情演示数据。

品牌名称统一使用完整的“鑫启网安俱乐部”，保持同一行。学校名称可单独置于其上方；正式组合署名为“宁夏大学 · 鑫启网安俱乐部”。

## 全片视觉与声音

- 背景为近黑、深海军蓝；Logo 的深蓝和亮蓝作为主色，冷白用于关键文字，红色用于异常，绿色用于正确提交。
- 主画面承担技术叙事，左上角仅标方向与任务，右侧按需要出现代码或数据。代码和字幕必须在手机观看尺度下可辨。
- 摄像机跟随有意义的对象运动：一个响应字段、一组密文、一条执行路径、一个内存地址。
- Logo 原图按原轮廓整理为矢量资产后制作动画，完整保留原造型。中央菱形被用作镜头入口，这是本片的视觉设计联想。
- 主版本采用音乐、音效、少量字幕。配乐建议采用 120 BPM、4/4 拍的暗色电子音乐，150 秒对应 75 小节；按分镜调整密度与强弱。
- 重要音效：终端输入、数据脉冲、断点锁定、失败提示、Flag 提交、成功提示。每个关键动作保留一种清晰的声音。
- 第一遍观看应能感受到“发现异常—提出假设—验证—获得结果”，技术细节服务这一过程。

声音：一次低沉启动音，伴随短促空间穿越声。

技术设计：采用自建演示题中的对象级授权缺陷。编号、会话身份、响应内容必须一致，异常具有可解释的原因。

转场：Flag 里的字符脱离窗口，重排成下一道题的密文。此处为图形匹配转场，各道题保持独立。

## 第三幕：Crypto｜00:32–00:52

### 镜头 08｜00:32–00:37｜截获密文

画面：字符阵列从纵深中靠近，摄像机停在一份 RSA 题目数据前。大部分字符退暗，关键参数被照亮。

界面文字：`02 / CRYPTO`；“弱参数分析”。

声音：节奏收紧，加入细密的数字脉冲。

### 镜头 09｜00:37–00:44｜抓住数学关系

画面：以小参数演示关系：`n = 3233`，两个因子块 `61`、`53` 拼合并验证 `61 × 53 = 3233`。随后展示 `e = 17`，演算路径连向恢复出的私钥指数。

字幕：**秘密，也有它的规律。**

技术设计：这是刻意缩小参数的可视化示例。画面角落标注“小参数示意”，随后用省略号进入正式题目计算。

声音：两个因子合拢时，响起一次清晰而短的锁定音。

### 镜头 10｜00:44–00:49｜数据恢复含义

画面：以 `c = 2790`、`d = 2753` 展示解密结果 `m = 65`，再映射为字符 `A`。随后多个字符按同一逻辑被恢复，重组为题目答案。

技术核对：`65^17 mod 3233 = 2790`，`2790^2753 mod 3233 = 65`。

声音：细碎脉冲逐渐形成稳定节奏。

### 镜头 11｜00:49–00:52｜解密完成

画面：短暂出现题目解出状态。最后一个字符向镜头放大，转为下一镜头的十六进制字符。

文字：`DECRYPTED`，随后小型“Correct”。

转场：用相同字形做匹配切换，进入另一道 Reverse 题。

技术设计：该片段表示输入处理的局部，寄存器状态与可视化同步。保持 `0x41 XOR 0x2a = 0x6b` 的数值一致。

声音：条件成立时加入一次干净的脉冲，音乐开始抬升。

## 制作拆分与交付

1. 使用 Remotion 组织章节、时间线、字幕、界面、音轨与渲染；用 Three.js 完成开场数据空间、网页分层、内存空间和片尾汇聚。
2. 先制作 00:00–00:32 的开场与 Web 样片，确定字体、配色、空间质感、转场和音效，再扩展其他章节。
3. 每章先输出关键帧，再生成低分辨率动画预览；根据实际预览调整信息密度与阅读时间。
4. Pwn、Reverse 和 Crypto 章节建立独立的演示数据文件，图形、代码、数值与运行结果共用同一份数据。
5. 交付 1080p MP4、封面、完整源工程、素材来源清单、运行与渲染说明。
6. 音乐、字体、音效的公开分发权限在素材清单中明确；参考视频通过链接记录。

## 验收重点

- 故事清楚：其余四题先后解出，Pwn 的未完成状态持续到最后，结尾回收前面的断点与地址线索。
- 黑客感来自具体观察与推理：画面中的每一次高亮、变更、放大，都指向一个有效发现。
- 技术可信：方向名称、数据、寄存器、汇编、字节、响应与结果互相对应。
- 文字可读：重要结果与字幕保持足够停留时间，中文字体无缺字，窗口内容不越界。
- 品牌一致：所有位置均使用完整名称“鑫启网安俱乐部”，姓名式简称与队名缩写不进入画面。
- 片尾可用：完整名称、Logo 与二维码清晰，二维码至少连续停留五秒。
- 音画完整：转场无黑帧，音效不压过关键提示，提交前静默与成功释放有明确层次。
