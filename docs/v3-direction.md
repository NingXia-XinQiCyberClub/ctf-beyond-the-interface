## 真实验证与影片重现

`npm run range`启动仅绑定127.0.0.1的临时HTTP服务，依次执行10个请求，随后关闭服务。业务数据完全虚构，没有真实企业目标、真实邮件投递或任意系统命令执行。任务接口只支持读取内置演练证明。

验证包含：合法对象200、跨对象200（缺陷）、越权任务201、蓝方策略与隔离、重试403；随后撤回临时来源封禁、修复对象授权和角色检查，复测越界403、任务403、合法200。关闭时清空临时任务。每个状态由真实HTTP返回并断言，记录在`src/data/range-evidence.json`。

影片展示业务界面、请求与SOC视图的动画重现，不把这些画面称为实战录屏或真实机构安全事件。

## ACE-Step音乐

使用官方ACE-Step Skill的CLI，在本机ACE-Step 1.5 turbo服务生成。CUDA、INT8权重、CPU卸载，辅助语言模型关闭。原C小样种子45307；将其保留前28秒并重绘延展至96秒，另以C为源作32秒蓝方变奏。任务与提示词在`public/music/generation-jobs.json`。

`public/music/C-theme.wav`、`C-extended.wav`、`C-blue.wav`为真实生成素材，重建150秒混音不需要模型服务。`npm run audio`进行剪辑、淡化、低通、增益、提示音避让与独立音效合成，输出`public/soundtrack-v3.wav`。编排和精确音效节点在`public/music/production-manifest.json`与`src/data/attack-cues.json`。

关键变化：86秒收静、87.3秒提交点击、88.3秒主题释放；90秒邮件到达并收低鼓组；98秒演练主节奏进入；红方推进与蓝方回应切换音色；122秒阻断短停；复测后逐步收束；140秒主题回归，148.6秒渐弱。音效不混作背景随机噪声。

请求150 BPM、D小调、4/4。对三份实际素材的10毫秒能量起音包络在近150 BPM区间作自相关检查，得到150 BPM候选周期；此检查不等于确认全部瞬态逐拍对齐，也不验证调性。具体动作由独立音效与剪辑控制。

## 重建与检查

安装Node 22+、Python 3.12与`requirements-audio.txt`。`npm ci`、`npm run assets`、`npm run range`、`npm run audio`、`npm run typecheck`后执行`npm run render`。音乐模型与CUDA依赖不属于视频重建的必需环境。

输出`dist/beyond-the-interface-v3.1-1080p.mp4`。检查源代表帧、最终MP4完整解码、4500帧及150秒、音频、关键节点、压缩后二维码。历史第二版文件独立保留。
