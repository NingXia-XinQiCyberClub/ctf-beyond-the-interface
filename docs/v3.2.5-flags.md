# v3.2.5 按题意区分 Flag

用户的新要求替代原本统一使用 flag{test} 的约定。统一数据源为 `src/data/challenge-flags.json`。

| 方向 | Flag | 对应解法 |
| --- | --- | --- |
| Web | `flag{check_the_owner}` | 越过对象授权边界后，提示必须检查对象归属 |
| Crypto | `flag{factor_to_decrypt}` | 分解弱 RSA 模数并恢复私钥 |
| Reverse | `flag{follow_the_true_path}` | 满足条件分支，抵达 success 路径 |
| Pwn | `flag{ret_to_win}` | 修正偏移，改写返回地址到目标函数；最终题中显示与提交 |
| Misc | `flag{read_the_lowest_bit}` | 提取图像蓝色通道最低有效位 |

Crypto 首字节演示同步改为 `1369^2753 mod 3233 = 102 → f`，完整密文数组可解密得到对应 Flag。Misc 使用该 Flag 的 200 位 ASCII 序列构造像素，并将提取范围同步更新为 `stream[:200]`。Web、Misc 的逐字显示按原显示时长调整速度，保持原音效时序。

Crypto、Reverse 的成功卡补上各自 Flag；Pwn 在最终挑战完成时展示，不提前将调试阶段标记为完成。完整音轨文件 SHA256 与 v3.2.4 一致。通过 `python tools/verify-flags.py` 校验唯一性、RSA 解密、LSB 提取和音轨一致性。
