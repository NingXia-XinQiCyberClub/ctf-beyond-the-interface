# v3.2.2 音效增强

按用户要求保留原 C《红蓝交锋》BGM 的编排、源音频和既有音量包络，仅增加和调整独立音效。完整重新绘制 4500 帧，1080p、30 fps、CRF18、medium。

- 保留既有提交、Correct、一血、排名、链路突破、阻断、报告保存和品牌音效；邮件到达提示增加谐波与衰减尾音，提高辨识度。
- 开场命令、红蓝终端和报告正文按实际显示字符的帧播放短键声。静止光标、即时结果输出及屏幕外正在输入的内容不触发键声；高速字符输入按两帧一声合并，避免密集噪声。
- 开场雷达、Misc 像素扫描、源会话定位增加扫描与完成反馈。CTF 使用 Root.tsx 的时间映射换算到最终片帧位。
- 邮件进入工作台及红蓝左右移动加入低音量空气滑动；终端弹窗、策略屏障和授权加固加入短反馈。
- 片尾二维码出现只有轻提示，不添加画面中不存在的手机扫码过程或扫码成功提示。
- 139–140 秒黑屏不增加音效。

复现：`npm run audio`、`npm run typecheck`、`npm run render`、`python tools/verify-v3.py`。音效均为原创程序合成，无新增外部素材依赖。

`scripts/foley-schedule.mjs` 直接读取终端命令、报告正文和 CTF 时间映射，输出逐帧事件表；`scripts/foley.py` 独立生成音效，不改变既有音效的随机序列。`outputs/sfx-upgrade/verification.json` 保存本次原音乐轨 SHA256 一致性、音效帧位和峰值检查结果。最终混音统一做响度及真峰值控制，音乐未改编。
