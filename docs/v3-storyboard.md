# 《表面之下》第三版修订视频脚本

2026-11-07用户确认视频脚本，音乐选择C《红蓝交锋》；护网结尾采用稿中A（修复复测、红蓝归一）。实现与实际音乐生成记录见`v3-direction.md`。

## 1. 本稿的结构

- 总时长暂维持150秒，1920×1080、30fps。
- 0–10秒：侦察、目标锁定与五方向，右上角加入SVG Logo与完整名称。
- 10–64秒：五个CTF方向压缩为54秒，保留“发现线索—突破—结果”，删减讲解停留与重复过程。
- 64–90秒：CTF篇最终提交、等待、CORRECT、一血、排名上涨，随后结束整个CTF大章节。
- 90–98秒：收到并打开护网行动邀请邮件，作为两个大章节之间的剧情转场。
- 98–140秒：护网/渗透测试演练，红方攻击、蓝方防守，交叉剪辑同一事件链；结尾采用本稿A方案。
- 140–150秒：保留已确认SVG Logo、完整名称“鑫启网安俱乐部”、口号“见微知隙，破阵无声。”与主页二维码。

本稿中的业务场景，指贴近企业业务的授权靶场：业务门户、API、运维节点、文件服务与安全监测。画面拟采用业务界面、终端、日志与拓扑联动。不是对真实企业发起攻击，也不把演练剧情包装成俱乐部的真实战绩。

## 2. 叙事与视觉规则

主线：第一大章节完整讲完CTF比赛并以最终提交和排名第一收束；收到护网行动邀请邮件后，第二大章节进入红蓝攻防演练，使用独立结尾衔接品牌落版，不再回到CTF。

原“138.3秒CORRECT、138.8秒一血”是第二版的定位时间。新草案把该组镜头前移为88.3秒CORRECT、88.8秒一血、约89秒排名上涨；保留其间隔与动作节奏，最终卡点待BGM试听后微调。第二版成片保留，第三版采用上述时间。

CTF篇沿用原有侦察蓝、突破红和成功绿。护网篇严格用红色标识攻击方、蓝色标识防守方：攻击方的侦察、尝试与调整始终带红方身份；防守方的监测、分析与处置始终带蓝方身份。界面同时保留RED TEAM / BLUE TEAM标签，不能只依靠颜色区分。绿色仅用于具体结果状态，不替换阵营色。Logo始终保留原配色。

主镜头始终展示具体动作与结果，不用连续大段代码或满屏随机字符代替攻防过程。攻守切换时保留同一网络拓扑、主机名、请求ID与时间线，使观众能看懂因果。

不设旁白，依靠音乐、界面音效和少量短句推进。若审计后需要旁白，再单独编写。

## 4. 音乐与转场要求

- 音乐采用用户审听选定的C《红蓝交锋》，基于其生成延展与蓝方变奏，保留旋律、和声与鼓贝斯律动；生成与编排记录见`v3-direction.md`及`public/music/`。
- 保留第二版150 BPM的工业电子风格；CTF用更密集的动作剪辑压缩时长，不通过全片统一倍速处理。
- 攻击进入时强调底鼓和失真低音，防守发现时转为更明确的高频节拍与短促提示，阻断/隔离动作落在重拍。
- 邮件段适度收低鼓组，保留邀请提示与打开/进入动作的可听性；进入演练时开启新乐句。
- 演练段不从头到尾维持同一强度：建立业务场景时留出阅读空间，入侵扩展加压，防守接管时切换音色，复测通过后释放。
- “排名第一→新邮件提示”“邮件→红队工作台”“同一请求/任务的攻守视角对切”“红蓝证据线→Logo”作为四处重点图形匹配转场。
- 保留CTF提交前的静默、点击、CORRECT与一血的相对节奏；绝对时间随章节前移。护网篇建立独立的第二次音乐发展与收束。
