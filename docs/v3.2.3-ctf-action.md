# v3.2.3 CTF 局部强化

用户要求按“五次破局”思路增强前段 CTF，并明确只替换必要部分。全片仍为 150 秒；BGM 保持原编排、源音频和音量包络。

本次修改：

- Web 在 11–13.2 秒插入直接访问被拒、转向对象接口的短镜头，再接回原请求比较和授权突破。拒绝发生在 `/admin`，后续对象接口的越权访问保留原来的成功响应。
- Crypto 在 22.7–24.7 秒插入排除错误因数的镜头，接回原模数分解；26 秒添加与分解同步的环形碎片。
- Reverse 保留原失败分支和成功分支，突出分支选择特写，在改向时加扩散反馈。
- Pwn 保留原崩溃与偏移修正，返回地址由逐字节写入完成，补充崩溃和修正的短音效。
- Misc 保留原像素剥离与提取，增加有限的镜头推进与关键识别提示。
- 最后一道题只在既有对齐、断点验证期间补充短诊断反馈。86 秒后恢复与此前相同的画面处理；提交、Correct、一血和排名时序保持原样。

镜头推进最高 7%，保持章节标题、代码和主图在画面内。新镜头和音效节点统一定义在 `src/data/ctf-action.json`。

音频先复现 v3.2.2 混音，再由 `scripts/ctf-foley.py` 叠加仅限 CTF 的短音效，不重新调整 BGM 或重新压缩整轨。新音效的增益根据剩余峰值余量降低，避免改变原音乐音量。对比确认音乐轨 SHA256 一致，86–150 秒母带 PCM 逐采样一致。

仍执行完整 4500 帧渲染，不复用旧 MP4 片段；邮件、红蓝护网、报告、黑屏和品牌二维码均沿用原场景实现。
