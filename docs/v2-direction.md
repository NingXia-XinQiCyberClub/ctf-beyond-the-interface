# 第二版制作记录

用户要求：增强“黑客”与“攻击”的意味，必要时由蓝转红；音乐更激烈，并与画面卡点。保留第一版最后 Flag 提交、排名上涨到结尾的设计。

## 视觉

150 秒、1920×1080、30fps、4500 帧的总规格与章节起点不变。

- 0–10s：新制攻击面网络图、侦察终端、目标锁定与五向量武装。
- 10–32s Web：变更对象请求、发现缺失 owner check、穿过授权边界、取得演示 Flag。
- 32–52s Crypto：拆开弱 RSA 模数、碎裂密钥空间、解密演示数据。
- 52–74s Reverse：追踪失败分支，解锁比较条件并通过校验。
- 74–96s Pwn：溢出崩溃、偏移修正、返回地址受控，悬念保留到终局。
- 96–114s Misc：扫描位平面，剥开表面并提取隐藏通道。
- 114–140s：保留最终提交、等待、CORRECT、一血与排名上涨；仅加强提交前的红色进攻状态和音乐推进。
- 140–150s：蓝色品牌落版、经用户审查确认的 SVG Logo、用户选定口号“见微知隙，破阵无声。”；二维码指向 https://ningxia-xinqicyberclub.github.io/ 。

颜色由侦察蓝经亮紫过渡到突破红，成功结果保留绿色。Logo 本身不改色。

## 转场与同步

章节通过 14 帧羽化扫描遮罩与轻微镜头推进连续衔接。前一场景在最后一帧短暂保持，下一场景仍按原起点计时；不存在剪短导致的终局偏移，也没有黑场淡入淡出。

音画事件来自同一个 `src/data/attack-cues.json`。150 BPM 每拍 0.4 秒，在 30fps 对应 12 帧，在 48kHz 对应 19200 个采样。突破前 160ms 的节奏收紧与停顿让冲击更明确；所有章节起点均为整拍，鼓组乐句按章节重新组织。

保留的特殊音效不强行吸附拍网格：137.3 秒点击提交、第 4149 帧（138.3 秒）CORRECT、第 4164 帧（138.8 秒）一血。它们是叙事优先的声音标点。

## Logo

`public/logo.svg` 是按原始 512×512 PNG 重绘的路径与渐变，没有 `<image>` 或 base64 位图。保留透明区域、中央菱形、深蓝双折线、青蓝交叉翼和原有配色。原始 `logo.png` 留作对照；Logo 品牌权利不纳入 MIT 授权。

用户已审查对照图并明确确认使用此版，随后授权加入丝滑转场。

## 本地导出

```sh
npm ci
npm run assets
npm run audio
npm run typecheck
npm run render
```

本机已有 Chrome 时也可运行 `node scripts/render-film.mjs`，输出 `dist/beyond-the-interface-v2-1080p.mp4`。可用 `REMOTION_BROWSER_EXECUTABLE` 指定浏览器，`RENDER_CONCURRENCY` 调整并发。原版成片与已发布 v1.0.0 保留。

## 成片复核

1080p成片已验证为4500帧、30fps、视频150.000秒、AAC音轨150.016秒，H.264全范围4:2:0（与第一版相同）。全片解码无错误。二维码从最终MP4的149秒帧中成功解码为指定主页。最终视频SHA256与详细参数保存在本地 outputs/v2-verification.json。
