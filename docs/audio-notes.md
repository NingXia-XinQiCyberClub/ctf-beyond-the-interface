# 配乐与音效

《表面之下》配乐为本项目程序合成的原创电子配乐，服务于鑫启网安俱乐部的 CTF 黑客主题宣传片。没有使用第三方录音、采样包、音乐下载或外部生成服务。

## 生成

```sh
node scripts/generate-audio.mjs
```

生成 `public/soundtrack.wav`，150 秒，48 kHz，双声道，16-bit PCM。程序使用固定随机种子，生成可复现。音频统计位于 `docs/audio-analysis.json`。

## 编排

- 120 BPM，4/4 拍，D minor / B-flat / F / C 和声循环。
- 0–10 秒：低频环境、终端键击、启动与穿越声，节奏逐渐建立。
- 10–74 秒：Web、Crypto、Reverse 使用低音、柔化琶音、电子鼓与轻量合成界面音推进。
- 74–96 秒：Pwn 段加重低频；81 秒左右失败短暂收紧，再恢复节奏。
- 96–114 秒：Misc 降低密度，让像素与隐写细节有呼吸空间。
- 114–136 秒：终局加密节奏，加入倒计时、键击与低频脉冲。
- 136–138.3 秒：配乐急收，137.3 秒点击提交，保留极低音量等待空间。
- 138.3 秒：正确提交，以低频撞击和上行和弦释放；138.8 秒一血提示。
- 140–150 秒：宽阔合成器尾声，143 秒品牌落版，最后 1.4 秒渐弱。

声源包括包络正弦/泛音合成器、低频鼓、滤波噪声军鼓与踩镲、合成机械键击、延迟和扩散混响。峰值归一化到 -1.5 dBFS，保留后续 AAC 编码余量；无削波。

## 使用方式

Remotion 中以一条全片音轨使用：

```tsx
<Audio src={staticFile("soundtrack.wav")} />
```

关键提交时刻：全片第 4119 帧（137.3s）点击、第 4149 帧（138.3s）Correct、第 4164 帧（138.8s）一血。视觉应与这些帧对齐，避免再叠加重复成功音。

源代码和合成结果按项目发布的许可证使用；没有随附第三方音乐的额外限制。
